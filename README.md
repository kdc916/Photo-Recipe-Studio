# Photo Recipe Studio WEB v0.5.1

GitHub Pages compatible offline photo recipe app.

## v0.5.1 focus
- GR Positive Film tuning
- Ricoh GR group default tuning
- stronger blacks, cooler neutrals, clearer red / cyan / magenta separation
- keeps film FX, EXIF assist, zoom, JPG export

## Deploy
Upload the contents of this folder to the root of your GitHub repository, then enable GitHub Pages with:
- Branch: `main`
- Folder: `/(root)`

## Main file
- `index.html`

No external CDN or backend is required.
